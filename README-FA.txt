Haleh CRM v2.5 - PWA Mobile

این بسته یک PWA نصب‌پذیر است.
برای نصب واقعی روی iPhone باید پوشه روی HTTPS میزبانی شود.
پس از باز کردن لینک در Safari:
Share > Add to Home Screen > Add

فایل‌های اصلی:
index.html
manifest.webmanifest
sw.js
icons/

نسخه برای تست محصول است و داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند.


نسخه آماده GitHub Pages. فایل‌های داخل این پوشه را مستقیماً در ریشه repository آپلود کنید.
